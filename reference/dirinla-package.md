# dirinla

The R-package dirinla allows the user to fit models in the compositional
data context. In particular, it allows fit Dirichlet regression models
using the Integrated Nested Laplace Approximation (INLA) methodology.

## Details

See
[`dirinlareg()`](https://inlabru-org.github.io/dirinla/reference/dirinlareg.md).

Tutorials and more information can be found at
<https://inlabru-org.github.io/dirinla/>

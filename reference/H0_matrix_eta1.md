# Computing expected Hessian for a vector eta

`H0_matrix_eta_1` computes the expected Hessian in eta of -loglikelihood

## Usage

``` r
H0_matrix_eta1(eta, d)
```

## Arguments

- eta:

  eta vector to compute the expected Hessian.

- d:

  Dimension

## Value

Expected Hessian in eta.

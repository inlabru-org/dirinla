# Summary using the packages Rfast and Rfast2 of a matrix by rows

`summary_fast` summarise a matrix by rows

## Usage

``` r
summary_fast(A)
```

## Arguments

- A:

  matrix to be summarised

## Value

A matrix whose columns are "mean", "sd", "0.025quant", "0.5quant",
"0.975quant"

## Author

Joaquín Martínez-Minaya <jomarminaya@gmail.com>
